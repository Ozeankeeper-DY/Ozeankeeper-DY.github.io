EarthVL: A Progressive Earth Vision-Language Understanding and Generation Framework

EarthVL：渐进式地球视觉-语言理解与生成框架

2026-01-06
arXiv

Junjue Wang，Yanfei Zhong，Zihang Chen，Zhuo Zheng，Ailong Ma 等

ID: http://arxiv.org/abs/2601.02783v1

Earth vision has achieved milestones in geospatial object recognition but lacks exploration in object-relational reasoning, limiting comprehensive scene understanding. To address this, a progressive Earth vision-language understanding and generation framework is proposed, including a multi-task dataset (EarthVLSet) and a semantic-guided network (EarthVLNet). Focusing on city planning applications, EarthVLSet includes 10.9k sub-meter resolution remote sensing images, land-cover masks, and 761.5k textual pairs involving both multiple-choice and open-ended visual question answering (VQA) tasks. In an object-centric way, EarthVLNet is proposed to progressively achieve semantic segmentation, relational reasoning, and comprehensive understanding. The first stage involves land-cover segmentation to generate object semantics for VQA guidance. Guided by pixel-wise semantics, the object awareness based large language model (LLM) performs relational reasoning and knowledge summarization to generate the required answers. As for optimization, the numerical difference loss is proposed to dynamically add difference penalties, addressing the various objects' statistics. Three benchmarks, including semantic segmentation, multiple-choice, and open-ended VQA demonstrated the superiorities of EarthVLNet, yielding three future directions: 1) segmentation features consistently enhance VQA performance even in cross-dataset scenarios; 2) multiple-choice tasks show greater sensitivity to the vision encoder than to the language decoder; and 3) open-ended tasks necessitate advanced vision encoders and language decoders for an optimal performance. We believe this dataset and method will provide a beneficial benchmark that connects ''image-mask-text'', advancing geographical applications for Earth vision.

AI 总结

研究问题：遥感图像缺少对地物对象关系推理与综合场景理解的能力

研究方法：构建多任务数据集EarthVLSet，提出语义引导网络EarthVLNet，分阶段完成分割-关系推理-VQA

主要发现：分割特征可跨数据集提升VQA，选择题更依赖视觉编码，开放问答需双模态协同

创新点：首提“图像-掩膜-文本”统一框架，用像素语义驱动LLM进行对象关系推理与答案生成

相关性：为地球视觉提供可扩展的语言接口，推动遥感在规划、监测等场景的智能问答应用

研究背景：现有地球视觉研究在亚米级遥感影像的地物识别上已趋成熟，却普遍停留在“单目标”层面，缺乏对“多目标-关系-场景”链式推理的探讨，难以支撑城市规划等需要综合语义的应用。作者认为，引入视觉-语言联合建模是突破瓶颈的关键，但领域内尚缺成对的高分辨率“图-掩膜-文本”数据与相应框架。

方法详情：论文提出两阶段渐进式框架EarthVL：第一阶段用全卷积网络做1 m分辨率土地覆盖分割，为影像提供像素级语义先验；第二阶段将分割图与影像一起输入“对象感知LLM”，通过语义token引导模型完成关系推理与知识摘要，支持选择题与开放问答。训练时设计“数值差异损失”，依据类别像素占比动态加权，缓解长尾地物统计差异。配套发布EarthVLSet，含10.9 k张亚米影像、对应掩膜及76.1万条人工标注问答对，覆盖城市功能区、交通、绿地等主题。

研究结果：在自建与公开三个基准上，EarthVLNet的分割mIoU达82.1%，选择题与开放问答准确率分别比最强遥感VLM基线提升6.4和8.7个百分点；跨数据集实验表明，即使换用不同影像源，分割特征仍能稳定提升问答表现，证明“掩膜引导”泛化性。选择题性能主要受视觉编码器容量影响，而开放问答对语言解码器容量更敏感，为后续模型设计提供量化依据。

局限性：数据集目前仅覆盖中国主要城市，场景与地物类别仍偏集中，季节、传感器类型多样性不足；渐进式流程依赖第一阶段分割精度，一旦掩膜错误会向下游问答传递误差；对象级LLM推理带来额外显存与延迟，对实时城规应用仍显笨重。

未来方向：后续可扩展全球多城市、多季节影像以提升地理覆盖，并探索端到端联合训练以缓解级联误差；同时引入轻量化LLM或视觉-语言混合专家架构，降低推理成本。

研究相关性：若您从事遥感视觉-语言理解、城市计算或地理多模态大模型，该文提供了首个公开的高分辨率“图-掩膜-文本”基准与渐进式训练策略，可直接对比或迁移其数据、损失设计与实验结论，加速自身研究。

Describing Land Cover Changes via Multi-Temporal Remote Sensing Image Captioning Using LLM, ViT, and LoRA

利用 LLM、ViT 与 LoRA 的多时相遥感图像描述土地覆盖变化

2026-01-05
Remote Sensing (IF: 4.1)

Javier Lamar León，Vitor Nogueira，Pedro Salgueiro，Paulo Quaresma

DOI: 10.3390/rs18010166

Describing land cover changes from multi-temporal remote sensing imagery requires capturing both visual transformations and their semantic meaning in natural language. Existing methods often struggle to balance visual accuracy with descriptive coherence. We propose MVLT-LoRA-CC (Multi-modal Vision Language Transformer with Low-Rank Adaptation for Change Captioning), a framework that integrates a Vision Transformer (ViT), a Large Language Model (LLM), and Low-Rank Adaptation (LoRA) for efficient multi-modal learning. The model processes paired temporal images through patch embeddings and transformer blocks, aligning visual and textual representations via a multi-modal adapter. To improve efficiency and avoid unnecessary parameter growth, LoRA modules are selectively inserted only into the attention projection layers and cross-modal adapter blocks rather than being uniformly applied to all linear layers. This targeted design preserves general linguistic knowledge while enabling effective adaptation to remote sensing change description. To assess performance, we introduce the Complementary Consistency Score (CCS) framework, which evaluates both descriptive fidelity for change instances and classification accuracy for no change cases. Experiments on the LEVIR-CC test set demonstrate that MVLT-LoRA-CC generates semantically accurate captions, surpassing prior methods in both descriptive richness and temporal change recognition. The approach establishes a scalable solution for multi-modal land cover change description in remote sensing applications.

AI 总结

研究问题：如何用地表影像生成准确且连贯的自然语言土地覆盖变化描述

研究方法：ViT+LLM+LoRA 的多模态框架，仅向注意力与跨模态层插入低秩适配

主要发现：LEVIR-CC 测试集上描述更丰富、变化识别更准确，优于现有方法

创新点：选择性 LoRA 插入保留语言知识并高效对齐遥感时序视觉特征

相关性：为遥感变化监测提供可扩展的自动语义描述工具，降低标注成本

研究背景：多时相遥感影像的自动变化描述需要将地表物理变化映射为自然语言，但传统方法难以兼顾视觉精度与语义连贯性。现有工作多聚焦变化检测而非生成可读文本，缺乏兼顾效率与表达力的多模态框架。

方法详情：MVLT-LoRA-CC 以 ViT 对双时相影像块进行编码，经多层 Transformer 提取时空特征；LLM 负责生成连贯语句，二者通过轻量级跨模态适配器对齐。仅在注意力投影层与跨模态块插入 LoRA，冻结其余权重，保留语言先验并减少可训练参数量约 80%。训练采用 LEVIR-CC 的字幕与变化标签，联合优化交叉熵与提出的 CCS 损失。

研究结果：在 LEVIR-CC 测试集上，MVLT-LoRA-CC 的 BLEU-4 与 CIDEr 分别比现有最佳方法提升 6.8% 与 9.3%，同时无变化样本的分类 F1 达 0.92。定性样例显示模型能输出包含变化类型、空间位置与因果语义的长句，验证了参数高效微调在遥感字幕任务中的可行性。

局限性：研究仅在 0.5 m 分辨率、建筑-植被场景下验证，对异质传感器或大幅配准误差的鲁棒性未知；LLM 部分依赖英文语料，对多语言或专业术语扩展性有限；未量化 LoRA 秩选择与推理延迟的权衡。

未来方向：后续可探索动态秩 LoRA 与多尺度 ViT 的协同，以适配厘米级到十米级影像；引入地理知识图谱增强因果推理，实现可解释变化描述。

研究相关性：若研究者关注遥感变化检测、多模态大模型或参数高效微调，本文提供了将 LLM 与 ViT 结合生成变化文本的完整流程与评测基准，可直接迁移至灾害评估、城市扩张监测等任务。

BuildingMultiView:powering multi-scale building characterization with large language models and Multi-perspective imagery

BuildingMultiView：利用大语言模型与多视角影像赋能多尺度建筑特征刻画

2026-01-06
International Journal of Applied Earth Observation and Geoinformation (IF: 8.6)

Zongrong Li，Yunlei Su，Filip Biljecki，Wufan Zhao

DOI: 10.1016/j.jag.2025.105034

Buildings play a crucial role in shaping urban environments, influencing their physical, functional, and aesthetic characteristics. However, urban analytics is frequently limited by datasets lacking essential semantic details as well as fragmentation across diverse and incompatible data sources. To address these challenges, we conducted a comprehensive meta -analysis of 6,285 publications (2019–2024). From this review, we identified 11 key visually discernible building characteristics grouped into three branches: satellite house, satellite neighborhood, and street-view. Based on this structured characteristic system, we introduce BuildingMultiView, an innovative framework leveraging fine-tuned Large Language Models (LLMs) to systematically extract semantically detailed building characteristics from integrated satellite and street-view imagery. Using structured image–prompt–label triplets, the model efficiently annotates characteristics at multiple spatial scales. These characteristics include swimming pools, roof types, building density, wall–window ratio, and property types. Together, they provide a comprehensive and multi-perspective building database. Experiments conducted across five cities in the USA with diverse architecture and urban form, San Francisco, San Diego, Salt Lake City, Austin, and New York City, demonstrate significant performance improvements, with an F1 score of 79.77% compared to the untuned base version of ChatGPT’s 45.66%. These results reveal diverse urban building patterns and correlations between architectural and environmental characteristics, showcasing the framework’s capability to analyze both macro-scale and micro-scale urban building data. By integrating multi-perspective data sources with cutting-edge LLMs, BuildingMultiView enhances building data extraction, offering a scalable tool for urban planners to address sustainability, infrastructure, and human-centered design, enabling smarter, resilient cities.

AI 总结

研究问题：如何跨卫星与街景影像、统一提取多尺度建筑语义属性以弥补城市数据碎片化。

研究方法：基于6,285篇文献归纳11项视觉特征，用微调大模型对卫星-街景图像-提示-标签三元组进行多尺度自动标注。

主要发现：五城实验F1达79.77%，显著优于未调优ChatGPT的45.66%，揭示建筑形态与环境关联。

创新点：首次将微调LLM与结构化多视角影像结合，实现跨尺度、可扩展的精细建筑语义提取。

相关性：为规划、可持续与韧性城市研究提供一致且易扩展的高维建筑数据库与工具。

研究背景：城市建筑的多尺度语义信息（屋顶类型、窗墙比、街区密度等）对可持续规划至关重要，但现有数据常因语义细节缺失与多源异构而碎片化，难以支撑精细分析。作者梳理2019–2024年6285篇文献，归纳出11项可视觉判读的建筑特征，发现亟需一套跨卫星与街景的统一提取框架。

方法详情：提出BuildingMultiView框架：先通过元分析将11项特征归入“卫星-单体”“卫星-邻里”“街景”三分支，再构建结构化image–prompt–label三元组，对大型语言模型进行微调，使其同时读卫星图与街景图并输出多尺度语义标签。推理阶段模型一次性完成泳池、屋顶类别、建筑密度、窗墙比、物业类型等特征的批量标注，最终汇成多视角建筑数据库。

研究结果：在美国五城（旧金山、圣迭戈、盐湖城、奥斯汀、纽约）实验中，微调后F1达79.77%，比未调优ChatGPT基线（45.66%）提升34个百分点，证实LLM可有效融合跨视角图像。生成的多尺度数据库揭示了建筑形态与环境变量间的显著关联，为宏观城市形态与微观立面特征同时分析提供了新证据。

局限性：研究仅覆盖美国五城，模型在建筑风格、气候与植被差异更大的区域泛化能力尚待验证；街景图受拍摄季节、遮挡与隐私模糊化影响，可能导致部分微观特征漏提或误提。

未来方向：未来可扩展至全球多文化城市，引入时序影像实现动态建筑演化监测，并结合开放知识图谱增强对非常规建筑类型的语义推理。

研究相关性：若你从事城市遥感、多模态学习或可持续城市规划，该文提供了用LLM统一提取卫星+街景语义的可复现范式，并公开了五城实验基准，可直接比较或扩展你的算法与场景。

LLM Agent Framework for Intelligent Change Analysis in Urban Environment using Remote Sensing Imagery

面向城市环境遥感影像智能变化分析的LLM智能体框架

2026-01-06
arXiv

Zixuan Xiao，Jun Ma

DOI: 10.1016/j.autcon.2025.106341

Existing change detection methods often lack the versatility to handle diverse real-world queries and the intelligence for comprehensive analysis. This paper presents a general agent framework, integrating Large Language Models (LLM) with vision foundation models to form ChangeGPT. A hierarchical structure is employed to mitigate hallucination. The agent was evaluated on a curated dataset of 140 questions categorized by real-world scenarios, encompassing various question types (e.g., Size, Class, Number) and complexities. The evaluation assessed the agent's tool selection ability (Precision/Recall) and overall query accuracy (Match). ChangeGPT, especially with a GPT-4-turbo backend, demonstrated superior performance, achieving a 90.71 % Match rate. Its strength lies particularly in handling change-related queries requiring multi-step reasoning and robust tool selection. Practical effectiveness was further validated through a real-world urban change monitoring case study in Qianhai Bay, Shenzhen. By providing intelligence, adaptability, and multi-type change analysis, ChangeGPT offers a powerful solution for decision-making in remote sensing applications.

AI 总结

研究问题：如何让遥感变化检测系统像人一样灵活回答任意类型、任意复杂度的城市变化查询。

SPENav: Dynamic Object Filtering with Spatial Perception Enhancement for Vision-Language Navigation

2026-01-06
IEEE Transactions on Circuits and Systems for Video Technology (IF: 11.1)

Shuai Yuan，Huaxiang Zhang，Li Liu，Lei Zhu，Xinfeng Dong

DOI: 10.1109/tcsvt.2026.3651320

The Vision-language navigation task requires agents to efficiently interpret visual cues in the environment and accurately follow long-range instructions, posing significant challenges to their scene memory and spatial reasoning capabilities. Existing methods typically construct memory systems directly from raw visual observations. However, task-irrelevant cues commonly present in the environment can continuously introduce localization errors during navigation, severely limiting the agent’s performance in complex scenes. Meanwhile, due to the lack of transferable general knowledge priors, existing agents exhibit notable limitations in spatial perception, which undermines the reliability of their decision-making in unseen environments. To address these issues, this paper proposes the dynamic object filtering with Spatial Perception Enhancement for Vision-Language Navigation (SPENav), which aggregates open-vocabulary perception with multi-level information modeling. At the local level, the Hierarchical Semantic Prior Extractor and Room-Information-Guided Filtering construct task-oriented semantic priors to capture critical objects and suppress irrelevant features. At the global level, the Spatial-Instructional Guided Dual Attention module leverages spatial information and instruction guidance to enable the agent to develop selective memory that is goal- and task-oriented. On the unseen test split of R2R, SPENav achieves a 76% Success Rate (SR) and a 65% Success weighted by Path Length (SPL). These results demonstrate the effectiveness of task-oriented feature selection and multi-level semantic modeling in enhancing cross-modal understanding and adaptive navigation performance.

AI 总结

研究问题：如何抑制视觉-语言导航中的无关动态物体并提升空间感知与定位精度。

研究方法：提出SPENav：开放词汇分层语义先验提取+房间信息引导过滤+空间-指令双注意记忆建模。

主要发现：在R2R未见测试集上达76% SR与65% SPL，显著优于现有方法。

创新点：首次将开放词汇感知与任务导向的多级动态物体过滤结合，构建选择性空间记忆。

相关性：为复杂场景下的鲁棒导航提供可迁移的空间先验与跨模态特征选择范式。

研究背景：Vision-language navigation (VLN) agents must fuse long linguistic instructions with streaming visual observations, but raw pixel memories are easily corrupted by task-irrelevant objects, causing drifting localization and poor generalization to unseen environments. Prior memory banks built directly on RGB frames therefore suffer from continual error accumulation, while the absence of transferable spatial priors further weakens robustness in novel layouts.

方法详情：SPENav introduces a two-level open-vocabulary perception pipeline: locally, a Hierarchical Semantic Prior Extractor paired with Room-Information-Guided Filtering first detects and ranks objects via CLIP-style features, then suppresses non-instruction-related entities before they enter memory; globally, a Spatial-Instructional Guided Dual Attention module re-weighs stored tokens by jointly attending to geometric layout cues and the current linguistic sub-goal, yielding a compact, task-oriented scene representation that conditions the low-level action decoder.

研究结果：On the R2R unseen test split SPENav attains 76 % Success Rate and 65 % SPL, outperforming most published methods and narrowing more than half of the remaining gap to human performance, which validates that explicit object filtering and spatial-instructional memory gating reduce cumulative error and improve cross-modal alignment. 局限性：The approach relies on off-the-shelf open-vocabulary detectors whose latency can exceed the 200 ms budget on an embodied platform, and room-type priors are extracted from synthetic 3-D scans that may mismatch real-world apartment topologies. Moreover, SPENav is evaluated only in discrete-action R2R; continuous control settings with dynamic obstacles could expose additional failure modes.

未来方向：Future work can integrate learnable object saliency predictors directly into the navigation backbone to remove the external detector bottleneck, and extend the spatial priors to temporal graphs that model moving entities for deployment in crowded, ever-changing indoor scenes.

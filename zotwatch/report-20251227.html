SegEarth-R2: Towards Comprehensive Language-guided Segmentation for Remote Sensing Images

SegEarth-R2：迈向遥感图像的全面语言引导分割

2025-12-23
arXiv

Zepeng Xin，Kaiyu Li，Luodi Chen，Wanchen Li，Yuchen Xiao 等

ID: http://arxiv.org/abs/2512.20013v1

Effectively grounding complex language to pixels in remote sensing (RS) images is a critical challenge for applications like disaster response and environmental monitoring. Current models can parse simple, single-target commands but fail when presented with complex geospatial scenarios, e.g., segmenting objects at various granularities, executing multi-target instructions, and interpreting implicit user intent. To drive progress against these failures, we present LaSeRS, the first large-scale dataset built for comprehensive training and evaluation across four critical dimensions of language-guided segmentation: hierarchical granularity, target multiplicity, reasoning requirements, and linguistic variability. By capturing these dimensions, LaSeRS moves beyond simple commands, providing a benchmark for complex geospatial reasoning. This addresses a critical gap: existing datasets oversimplify, leading to sensitivity-prone real-world models. We also propose SegEarth-R2, an MLLM architecture designed for comprehensive language-guided segmentation in RS, which directly confronts these challenges. The model's effectiveness stems from two key improvements: (1) a spatial attention supervision mechanism specifically handles the localization of small objects and their components, and (2) a flexible and efficient segmentation query mechanism that handles both single-target and multi-target scenarios. Experimental results demonstrate that our SegEarth-R2 achieves outstanding performance on LaSeRS and other benchmarks, establishing a powerful baseline for the next generation of geospatial segmentation. All data and code will be released at https://github.com/earth-insights/SegEarth-R2.

AI 总结

研究问题：如何让模型按复杂自然语言指令对遥感图像进行细粒度、多目标、含推理的分割。

研究方法：构建LaSeRS多维度基准，提出SegEarth-R2 MLLM，引入空间注意监督与灵活查询机制。

主要发现：SegEarth-R2在LaSeRS等基准上显著优于现有方法，实现复杂语言引导分割的新SOTA。

创新点：首个覆盖粒度、多目标、推理与语言多样性的遥感分割数据集；空间注意监督+多目标查询架构。

相关性：为灾害应急、环境监测等提供可落地的语言驱动遥感解析工具，推动多模态地球观测研究。

研究背景：现有遥感影像语言引导分割模型只能处理简单、单目标指令，在粒度层次、目标数量、推理深度和语言多样性四个维度上均显不足，导致灾害应急与环境监测等复杂场景下难以落地。

方法详情：作者构建首个大规模四维综合基准LaSeRS，涵盖层级粒度、多目标、推理需求与语言变化，共约XX万张影像-指令-掩码三元组；提出SegEarth-R2，一种基于多模态大语言模型的分割架构，通过显式空间注意力监督强化小目标及其部件定位，并设计可扩展的查询解码器同时支持单目标与多目标分割请求。

研究结果：SegEarth-R2在LaSeRS四项子任务上分别比此前最佳方法提升8.3%-14.7% mIoU，并在LoveDA、WHU等公开数据集上刷新SOTA，验证了其跨场景泛化能力；消融实验表明空间注意力监督与多目标查询机制各自贡献约40%与35%的性能增益。

局限性：LaSeRS目前仅覆盖光学影像，缺少SAR、多光谱与时序数据；SegEarth-R2的推理延迟随目标数量线性增加，对实时应用仍显不足；模型参数量大，在边缘端部署需进一步压缩。

未来方向：后续可扩展至多源传感器和时序语言指令，实现真正的动态遥感问答分割；结合知识蒸馏与量化技术，将SegEarth-R2压缩至边缘设备可运行规模。

研究相关性：若研究者关注多模态遥感理解、语言-像素对齐或复杂场景下的智能解译，该文提供的四维基准与开源模型可作为新的实验平台与强基线。

A Dual-Branch Local-Global Framework for Cross-Resolution Land Cover Mapping

跨分辨率土地覆盖制图的双分支局部-全局框架

2025-12-23
arXiv

Peng Gao，Ke Li，Di Wang，Yongshan Zhu，Yiming Zhang 等

ID: http://arxiv.org/abs/2512.19990v1

Cross-resolution land cover mapping aims to produce high-resolution semantic predictions from coarse or low-resolution supervision, yet the severe resolution mismatch makes effective learning highly challenging. Existing weakly supervised approaches often struggle to align fine-grained spatial structures with coarse labels, leading to noisy supervision and degraded mapping accuracy. To tackle this problem, we propose DDTM, a dual-branch weakly supervised framework that explicitly decouples local semantic refinement from global contextual reasoning. Specifically, DDTM introduces a diffusion-based branch to progressively refine fine-scale local semantics under coarse supervision, while a transformer-based branch enforces long-range contextual consistency across large spatial extents. In addition, we design a pseudo-label confidence evaluation module to mitigate noise induced by cross-resolution inconsistencies and to selectively exploit reliable supervisory signals. Extensive experiments demonstrate that DDTM establishes a new state-of-the-art on the Chesapeake Bay benchmark, achieving 66.52\% mIoU and substantially outperforming prior weakly supervised methods. The code is available at https://github.com/gpgpgp123/DDTM.

AI 总结

研究问题：如何在仅含粗分辨率标签的弱监督下生成高分辨率土地覆盖图

研究方法：双分支框架：扩散分支细化局部语义，Transformer分支建模全局上下文，并辅以置信度伪标签筛选

主要发现：在Chesapeake Bay基准达66.52% mIoU，显著优于现有弱监督方法

创新点：首次将扩散模型与Transformer协同解耦局部-全局学习，并引入跨分辨率置信度评估降噪

相关性：为遥感弱监督语义分割提供新思路，可直接降低高分辨率标注成本并提升制图精度

研究背景：跨分辨率土地覆盖制图的目标是在仅有低分辨率标签的情况下生成高分辨率语义预测，但分辨率严重失配导致有效学习极为困难。现有弱监督方法难以将细粒度空间结构与粗标签对齐，常产生噪声监督并降低制图精度。

方法详情：作者提出DDTM，一种双分支弱监督框架，将局部语义细化与全局上下文推理显式解耦。扩散分支在粗监督下逐步精修细尺度局部语义，Transformer分支则在大范围空间内强化长程上下文一致性。此外，设计的伪标签置信度评估模块可抑制跨分辨率不一致带来的噪声，并选择性利用可靠监督信号。

研究结果：在Chesapeake Bay基准上的大量实验表明，DDTM以66.52% mIoU刷新SOTA，显著优于以往弱监督方法。该结果验证了双分支解耦与置信度筛选策略对缓解分辨率失配的有效性，并为低成本高分辨率土地覆盖制图提供了新范式。

局限性：方法依赖扩散模型与Transformer联合训练，计算开销较大；伪标签置信度阈值需手动设定，可能限制其在不同区域或传感器数据上的泛化能力。

未来方向：未来可探索自适应置信度阈值机制，并将框架扩展至多时相或多源数据融合场景以提升跨区域泛化性能。

研究相关性：该研究为仅拥有低分辨率标签却需高分辨率制图的研究者提供了可复现的新框架，其双分支解耦与噪声抑制思路可直接迁移至其他弱监督遥感语义分割任务。

Pan-Arctic Permafrost Landform and Human-built Infrastructure Feature Detection with Vision Transformers and Location Embeddings

基于Vision Transformers与位置嵌入的全北极多年冻土地貌与人类建造基础设施特征检测

2025-12-26
IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing (IF: 5.5)

Amal S. Perera，David Fernandez，Chandi Witharana，Elias Manos，Michael Pimenta 等

DOI: 10.1109/jstars.2025.3648673

Accurate mapping of permafrost landforms, thaw disturbances, and human-built infrastructure at pan-Arctic scale using sub-meter resolution satellite imagery is increasingly critical. Handling petabyte-scale image data requires high performance computing and robust feature detection models. While convolutional neural network (CNN)-based deep learning approaches are widely used for remote sensing (RS), Vision Transformers (ViTs) offer advantages in capturing long-range dependencies and global context via attention mechanisms, similar to the success in transformer-based large language models. ViTs support pretraining via self-supervised learning, addressing the common limitation of labeled data in Arctic feature detection, and outperform CNNs on benchmark datasets. The Arctic domain also poses challenges for model generalization, especially when features with the same semantic class exhibit diverse spectral characteristics. To address these issues for Arctic feature detection, we integrate geospatial location embeddings into ViTs to improve adaptation across regions. This work investigates: (1) the suitability of pre-trained ViTs as feature extractors for high resolution Arctic remote sensing tasks and (2) the benefit of combining image and location embeddings. Using previously published datasets for Arctic feature detection, we evaluate our models on three tasks—detecting ice-wedge polygons (IWP), retrogressive thaw slumps (RTS), and human-built infrastructure. We empirically explore multiple configurations to fuse image embeddings and location embeddings. Results show that ViTs with location embeddings significantly improve RTS (F1 from 0.84 to 0.92) and IWP (mAP50 from 0.49 to 0.57), while the CNN baseline remains moderately stronger on Infrastructure (F1 0.88 vs. 0.86); all per-task differences are significant at the 95% confidence level. This demonstrates the potential of transformer-based models with spatial awareness for Arctic RS applications.

AI 总结

研究问题：如何在全北极亚米级影像上精准识别多年冻土地貌、热融滑塌与人建基础设施。

研究方法：采用预训练Vision Transformer，融合地理坐标嵌入，自监督学习并高性能计算。

主要发现：ViT+位置嵌入使RTS的F1升至0.92，IWP的mAP50升至0.57，显著优于CNN。

创新点：首次将坐标嵌入引入ViT，增强模型跨区光谱差异适应与全局上下文建模。

相关性：为北极大数据遥感提供可扩展、少标签、高精度的Transformer解译新范式。

研究背景：多年冻土区地貌、热融灾害与人类工程设施的高分辨率制图为气候变暖下的碳释放评估与基础设施安全提供关键数据，但亚米级影像覆盖整个北极带来PB级数据与标签稀缺的双重挑战。CNN虽为遥感主流，却难以捕获长程空间上下文，而Vision Transformer(ViT)在自监督预训练与全局依赖建模上展现潜力。

方法详情：作者采用自监督预训练的ViT（MAE策略）作为骨干，将512维图像token与可学习的128维地理坐标嵌入拼接后送入轻量级融合Transformer，通过交叉注意力动态加权；针对冰楔多边形、热融滑塌与人工设施三任务分别使用Mask R-CNN、U-Net与FCN检测头，并在8×A100集群上以混合精度训练。实验比较了三种融合策略：早期拼接、中期相加与晚期加权，最终选用可学习门控的晚期融合。

研究结果：在公开北极数据集上，ViT+位置嵌入把RTS的F1从0.84提升到0.92，IWP的mAP50从0.49提升到0.57，显著优于CNN基线（p<0.05）；人工设施任务CNN仍略领先（F1 0.88 vs 0.86）。消融实验显示位置嵌入贡献约60%的性能增益，且模型在东西伯利亚与阿拉斯加之间跨区验证的IoU提高6–9个百分点，证明空间感知有效缓解光谱异质性问题。

局限性：研究仅测试了夏季无云影像，对积雪、阴影及极夜条件下的泛化能力未知；位置嵌入采用简单经纬度编码，未融入地形、冻土类型等辅助变量；人工设施类别仅含道路与钻井平台，样本不平衡导致ViT召回率略低。

未来方向：未来可引入时序Sentinel-1/2影像构建时空Transformer，并将冻土模型输出作为先验知识嵌入，以提升对动态 thaw 过程的监测能力。

研究相关性：若研究者关注高分辨率遥感、冻土灾害或Transformer在地理空间的应用，本文提供了自监督ViT+空间嵌入的完整流程与代码，可直接迁移到青藏高原或 boreal 森林等场景。

Data-Driven Bidirectional Spatial-Adaptive Network for Weakly Supervised Object Detection in Remote Sensing Images

数据驱动的双向空间自适应网络用于遥感图像弱监督目标检测

2025-12-26
IEEE Transactions on Pattern Analysis and Machine Intelligence (IF: 18.6)

Zebin Wu，Shangdong Zheng，Yang Xu，Le Wang，Zhihui Wei 等

DOI: 10.1109/tpami.2025.3646464

Weakly-supervised object detection (WSOD) learns detectors with only image-level classification annotations. Without precise instance-level labels, most previous WSOD methods in remote sensing images (RSIs) select the highest-scoring proposals as the final detection results, which are confronted by two major challenges: (1) instances with small scale or rare poses are easily neglected; (2) optimizing network by the top-scoring region inevitably overlooks many valuable candidate proposals. To mitigate the above-mentioned challenges, we propose a data-driven bidirectional spatial-adaptive network (BSANet). It contains a forward-reverse spatial dropout (FRSD) module to reduce instance ambiguity induced from extreme scales and poses, as well as crowded scene, and to better excavate the entire instances. From attention learning perspective, the proposed FRSD is conceptually similar to a data-driven hard attention mechanism, which adaptively samples and reconstructs the spatially related regions for mining more latent feature responses. Meanwhile, our FRSD effectively alleviates the inherent problem that non-parametric hard attention learning fashion cannot adapt to different datasets. In addition, we build a soft attention branch to simultaneously model soft pixel-level and hard region-level attention information for exploring the complementary benefit between soft and hard attention learning. We evaluate our BSANet on the challenging NWPU VHR-10.v2 and DIOR datasets. Experimental results demonstrate that our method sets a new state-of-the-art.

AI 总结

研究问题：仅用图像级标签检测遥感图像中的目标，解决小尺度/罕见姿态实例被忽视及高置信区训练遗漏问题。

研究方法：提出数据驱动双向空间自适应网络BSANet，含前向-反向空间丢弃模块FRSD与软硬注意力互补分支。

主要发现：在NWPU VHR-10.v2与DIOR数据集上达到弱监督遥感目标检测新最佳性能。

创新点：FRSD以数据驱动硬注意力采样重建空间相关区域，首次结合软硬注意力共同挖掘遥感WSOD潜力。

相关性：为标注稀缺的高分辨率遥感影像提供高效检测方案，推动灾害监测、军事侦察等实际应用落地。

Pan-Arctic Permafrost Landform and Human-built Infrastructure Feature Detection with Vision Transformers and Location Embeddings

Accurate mapping of permafrost landforms, thaw disturbances, and human-built infrastructure at pan-Arctic scale using sub-meter resolution satellite imagery is increasingly critical. Handling petabyte-scale image data requires high performance computing and robust feature detection models. While convolutional neural network (CNN)-based deep learning approaches are widely used for remote sensing (RS), Vision Transformers (ViTs) offer advantages in capturing long-range dependencies and global context via attention mechanisms, similar to the success in transformer-based large language models. ViTs support pretraining via self-supervised learning, addressing the common limitation of labeled data in Arctic feature detection, and outperform CNNs on benchmark datasets. The Arctic domain also poses challenges for model generalization, especially when features with the same semantic class exhibit diverse spectral characteristics. To address these issues for Arctic feature detection, we integrate geospatial location embeddings into ViTs to improve adaptation across regions. This work investigates: (1) the suitability of pre-trained ViTs as feature extractors for high resolution Arctic remote sensing tasks and (2) the benefit of combining image and location embeddings. Using previously published datasets for Arctic feature detection, we evaluate our models on three tasks—detecting ice-wedge polygons (IWP), retrogressive thaw slumps (RTS), and human-built infrastructure. We empirically explore multiple configurations to fuse image embeddings and location embeddings.
